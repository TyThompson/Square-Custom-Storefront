# Northline Goods — Square-backed custom storefront

Example Next.js storefront with Square Web Payments SDK, Orders API, and on-site order tracking. No Square Online site required.

## Run locally

```bash
npm install
npm run dev
```

Open http://127.0.0.1:43123

Copy `.env.example` to `.env.local` for Square sandbox credentials. Without them, demo/mock mode still runs the full browse → checkout → track flow.
